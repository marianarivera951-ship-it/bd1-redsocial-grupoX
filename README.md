## Descripción del Caso
El objetivo principal de este proyecto es diseñar el modelo conceptual de base de datos para una plataforma de red social estudiantil universitaria. La solución busca facilitar la interacción casual entre estudiantes, el intercambio de conocimientos, la tutoría entre pares, la creación de grupos de estudio y la organización de eventos o actividades académicas y sociales.
